# 拾念 · 游戏创意档案

把散落在 ChatGPT 和 Codex 对话里的游戏创意，沉淀为可以继续的项目资料。

一套桌面 / 手机共用 PWA，GitHub 保存资料，不需要自建服务器、数据库或模型 API Key。

**应用已发布：[打开拾念 · Idea Grove](https://lcy199608.github.io/idea-grove/)。遵照项目要求，未运行测试、浏览器功能验收或真实 GPT 联调；Pages 发布工作流已成功。**

应用源码：[lcy199608/idea-grove](https://github.com/lcy199608/idea-grove)。首次在「同步设置」填写你自己的资料仓库所有者、仓库名和分支，并自行填写有 Contents 读写权限的令牌。

若此前在 localhost 保存了内容，请先在旧页面「备份与导入」中导出，再到正式网址导入。不同网址的本地资料和登录不会自动迁移。

## 在本机打开

需要 Python 3.9 或更新版本。在项目根目录执行：

```sh
python3 scripts/serve.py
```

浏览器打开 <http://localhost:4173>。此命令仅在自己的电脑启动静态预览，不是要购买或维护一台服务器。不要直接双击 index.html 使用 file://，ES Modules、IndexedDB、Service Worker 和 Web Locks 需要合适的浏览器环境。

先点「看看示例」了解界面，或「创建第一个主题」从空白开始。示例只有点击后才进入本地资料，允许编辑、删除，不会自动上传。

## 功能

- 主题创建、编辑、标签与删除。
- 模块创建、编辑、删除、搜索、状态筛选和 Markdown 阅读。
- 正文图文混排：手机选图、电脑在正文光标处粘贴/拖入图片，编辑区直接显示图片，可在图前图后输入，支持 Markdown 源码切换、撤销、放大、下载和删除，随 GitHub、备份和草稿同步保存。
- 已确认 / 待探索 / 已放弃；接续上下文默认排除已放弃内容。
- 项目概览、上下文复制与 Markdown 下载。
- 本地资料与编辑草稿保存在 IndexedDB；支持离线编辑。
- GitHub 手动拉取 / 上传，三方比较、按主题处理冲突，整批修改作为一次提交上传。
- 删除与另一端修改相遇时显示冲突，避免旧设备悄悄恢复删除内容。
- 资料备份导入 / 导出、冲突副本下载、导入前恢复副本。
- 单个来源只允许一个编辑窗口，避免本地多标签页覆盖草稿。
- 拾念插件/Skill 通过云端连接配置记住个人资料仓库，通过 GitHub 插件读取与按要求保存；支持“继续讨论”“整理本次讨论”等自然语言，见 [使用说明](docs/codex.md)。
- 内置私人 GPT 指令与按当前仓库生成的 Actions 配置下载（需要账号提供 Actions 入口）。
- 可安装的 PWA、响应式布局、应用图标与静态离线缓存。

## 首次接入 GitHub

1. 创建一个**私有资料仓库**，例如 `game-ideas`，勾选添加 README，使 `main` 分支已经存在。
2. 在 GitHub 创建 fine-grained personal access token，仅选择该仓库，给予 **Contents: Read and write**。
3. 在应用「同步设置」填写所有者、仓库名、分支与令牌。
4. 点击「拉取」读取资料。如果在连接前已写了本地内容，可以在首次连接时勾选带上这些资料。
5. 编辑后点击「上传」。其他设备点击「拉取」接续。

点击「保存并记住登录」后，令牌保存在当前设备、当前浏览器的 IndexedDB 独立凭据区，刷新页面、关闭后重开及重启浏览器都会自动恢复。应用不设登录有效期；GitHub 令牌自身到期、撤销、权限变更，以及浏览器清理站点数据仍会影响登录。每个设备首次填写一次，凭据不会随 GitHub 或备份同步。

在「同步设置 → 清除此设备全部登录」可主动移除所有已保存仓库的凭据，同时保留仓库设置、主题、草稿与备份。「切回本地空间」只切换工作区，不清除登录；再次填写已保存的仓库所有者与名称会恢复令牌。凭据不进入资料文件、导出备份、Git 提交或日志；这只清除本机记忆，不会撤销 GitHub 上的令牌或其他设备的登录。

旧版选择了会话记住且当前标签页还持有凭据时，升级后会迁移到长期存储；旧版仅在内存中保存的令牌，需要重新填写并保存一次。应用会尝试申请浏览器持久存储，但无痕模式、系统回收或人为清理数据无法由应用保证。不要把令牌发在聊天中。

仓库 / 分支各有独立本地工作区。切换仓库不会把另一份仓库的旧草稿混入；切回同一仓库会恢复该设备已有草稿。未连接空间的资料也独立保留。

## 发布到 GitHub Pages

使用两个仓库：

- **应用仓库**：本项目源码，用 GitHub Pages 发布 web/。GitHub Free 需要公开应用仓库。
- **资料仓库**：始终独立且私有，只有授权后通过 API 读取，不能复制进 web/。

本项目已提供 `.github/workflows/pages.yml`，只上传 `web/` 静态资源，不执行测试或构建。

1. 将本项目源码上传到你用于发布的 GitHub 仓库，默认分支使用 `main`。
2. 仓库 Settings → Pages → Source 选择 **GitHub Actions**。
3. 在 Actions 中手动运行 **Publish PWA to GitHub Pages**，或提交 web/ 的修改触发发布。
4. 工作流完成后，打开 Pages 提供的网址。
5. 在手机打开同一网址，并通过浏览器菜单添加到主屏幕。支持 PWA 安装的桌面浏览器也可安装。

若默认分支不是 main，需要同步修改工作流的触发分支。应用使用相对地址，同时适配 `username.github.io/` 与 `username.github.io/project/`。应用每次发布修改缓存资源时，应提升 web/sw.js 的 CACHE 版本；关闭所有旧窗口再打开应用以启用新版本。

本项目已上传至 `lcy199608/idea-grove` 并启用 Pages。资料仓库由每位用户自行选择并初始化。浏览器仍需首次配置仓库和令牌；ChatGPT 安装拾念插件后单独连接 GitHub。源码和发布文件不包含任何登录令牌。

## 使用参考图

进入主题 → 新增或编辑模块 → 将正文光标放在需要插图的位置 → 直接粘贴图片，或点击「插入图片」选图，也可先定位光标再拖入文件。图片直接显示在当前编辑位置，与文字在同一区域编辑。点击图片下方「在下方输入」可继续写下一段，也可以「移除此处图片」或「放大」。保存后上传，其他设备拉取即可看到相同图文。

默认图文编辑把图片引用显示为图片，文字部分保留 Markdown 标记；需要查看或调整原始内容时，点「Markdown 源码」，再点「图文编辑」切回。支持正文撤销/重做（⌘/Ctrl+Z、⌘/Ctrl+Shift+Z），剪切/粘贴同模块图文可调整位置。

保存的正文使用标准的相对图片路径，例如 `![参考图说明](../images/<module-id>/<image-id>.webp)`，因此模块 Markdown 在 GitHub 中也能定位同仓库的图片。移动/复制该引用即可移动/重复展示图片，不增加重复文件。点击正文图片可放大和下载。代码块、行内代码内的图片语法仅作为文字展示。

「管理图片」默认收起；已有旧附件可以点「插入正文」，不用重新上传。「移除此处图片」或删除正文引用只移除该处展示，文件保留在管理区，便于重新插入；点击「删除图片与引用」会清理正文中该图的有效引用和文件，保存并上传后同步删除。旧版未插入正文的附件仍显示在文章末尾，避免升级后隐藏已有资料。

每模块最多 10 张，支持 JPG、PNG、WebP；原文件不超过 20 MB。自动压缩至最长边 2560 像素、单张不超过 1.5 MB，保留透明背景，原图请自行保存。GIF 仅保留静态画面；HEIC 是否可读取决于浏览器，不支持时请转成 JPG/PNG。单个资料库的图片总量最多 40 MB。

参考图位于独立私有资料仓库，应用不使用公共图床，不将访问令牌放入图片地址。图片纳入正式备份、未完成草稿和主题冲突处理。备份支持旧版纯文字资料；首次保存图片后资料版本自动升级为 v2，请先在其他设备关闭全部旧页面并重新打开以更新应用，Codex 也需使用更新后的 Skill。

「接续上下文」会带上参考图的名称、说明和仓库路径，但复制文字不会自动传送图片。需要在 ChatGPT 中分析时，可下载参考图并上传到聊天。拾念插件现可在具备附件原文件读取和文件处理能力的环境中，将有价值聊天参考图随正文同次保存；缺少原文件通道时会明确说明，不能把视觉分析当作图片已经上传。旧 GPT Actions 配置仍仅维护文字、保留/删除已有附件，入口是否可用需按账号确认。

本次正文图文编辑功能未运行自动或人工功能测试，验收步骤见 [人工验收清单](docs/manual-acceptance.md)。

## 参考资料（v3，新功能待人工验收）

主题中新增「参考资料」页，可登记来源、版本、解析状态、验证状态、关联模块和旧版本，分别添加原件、解析结果与核对依据。支持本机草稿、文本预览、下载、重复原件提示、GitHub原子同步与备份。接续上下文包含资料索引，AI按需读取。

单文件最多8 MiB、每份最多32文件、每主题100份、参考文件总量64 MiB。大地图等超限原件不自动上传，应记录来源和SHA-256并标注未归档。普通文件保留原字节；网页端不自动解析PDF、表格或地图，可由AI生成解析文件再归档。HTML与脚本只作纯文本预览。

**先发布/更新网页并重新安装0.4.0插件，再启用参考资料或导入v3备份。** 旧客户端不兼容v3，不能在其上写入新资料。现有v1/v2库不会在打开时自动升级。此次遵照AGENTS.md未运行测试、页面预览或浏览器验收。

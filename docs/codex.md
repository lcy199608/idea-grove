# 拾念 Skill：一次配置，直接说需求

技能源文件位于 `.agents/skills/game-idea-vault/`。默认资料库在 `references/repository.json` 中配置为 `lcy199608/game-ideas`、分支 `main`；不含令牌。换仓库只需修改这份配置，不必每次贴链接。

## 日常使用

- `用拾念打开我的创意库。`：读取远端，列出主题。
- `用拾念继续讨论回声森林，先不保存。`：先读已有共识再讨论。
- `用拾念整理本次讨论。`：展示拟新增/修改/删除及状态，不写入。
- `保存第 1、3 项，第 2 项作为待探索，其余不保留。`：在当前主题范围内保存，一次提交，返回链接。
- `把刚才确认的内容保存到拾念。`：内容明确时直接保存；没有明确结论时先澄清，不把所有 AI 建议当成决定。

首次需要时可显式选择 `$game-idea-vault`；后续使用“拾念”等自然语言可匹配技能。新聊天仍会读取远端，不把聊天记忆当成最新资料。

## 本机安装

将整个技能文件夹复制到个人技能目录 `~/.codex/skills/game-idea-vault/`。存在旧版时先查看并保留自定义内容，再选择需要更新的文件；不盲目覆盖。

本次已安装到当前 Mac 的个人技能目录。新聊天可选择「拾念」；若技能列表未更新，重启应用。安装文件不会自动同步到其他电脑或手机。

## GitHub 插件（默认通道）

使用已连接的 GitHub 插件直接读取及原子提交，无需克隆仓库或另设服务器。实际读写权限由插件连接和 GitHub 决定，Skill 只负责工作流，不能授予权限。

列主题时必须读取完整目录，不能把搜索无结果当空库。只有 README 的仓库尚未建立拾念资料；若本地已有主题，请先在拾念保存并上传。技能不会因列主题请求自行初始化。

## 本地 Git（可选通道）

用户明确指定本地资料库时，使用技能的 `references/local.md` 和 `scripts/vault.py`。须检查远端是否与配置对应，不能向应用源码目录写入创意。工作区有修改时保留现场，不 reset、stash 或强推。

## ChatGPT 网页和手机

本地 Skill 与账号中的云端插件不是同一项安装。网页/手机使用时，将技能规则作为「拾念」插件的技能，并包含已连接的 GitHub 应用。一次创建完成后，聊天中选 `@拾念` 即可，不需重复仓库地址。

创建步骤和可直接提交的说明见 [ChatGPT 接入](../integrations/chatgpt/README.md)。云端插件是否创建成功、是否可在手机选择，以账号实际界面为准；生成文件不等于完成云端安装。

## 状态与验收

AI 保存成功后，拾念点「拉取」；在拾念编辑后点「上传」，再换设备或交给 AI 修改同一主题。图片由拾念添加上传，Skill 保留图片与正文排版，不自动收集聊天附件。

本次只创建/安装技能文件，不读取或修改真实创意资料，不创建验收主题，不运行测试或验证器。实际写入须由用户人工验收。

官方参考：[构建技能](https://learn.chatgpt.com/docs/build-skills)、[创建插件](https://learn.chatgpt.com/docs/build-plugins)。

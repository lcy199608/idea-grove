# 人工验收清单

所有条目均为**待人工执行**；本次开发没有运行这些检查。推荐先使用独立的私有验收仓库（带 README），不要在重要资料上首次试用。

## 本机与手机

- [ ] 按 README 启动静态预览，首次显示空白引导，没有自动生成、上传示例资料。
- [ ] 点「看看示例」，出现一个主题、三个模块；说明中能识别是示例。
- [ ] 创建主题、编辑描述/标签，刷新页面后仍存在。
- [ ] 新增模块，编辑中文 Markdown、类型、状态、原因和来源，保存后再次打开内容一致。
- [ ] 编辑过程中直接关掉弹窗，再打开相同模块或「新增模块」，能恢复草稿；丢弃后重新读取正式内容。
- [ ] 在中文输入法组合过程中搜索，输入不中断；关键词匹配标题与正文。
- [ ] 筛选三种状态；项目概览区分已确认与待探索。
- [ ] 接续上下文排除已放弃；取消包含待探索后只保留已确认。
- [ ] 删除单个模块不会删除其他模块；删除主题会删除其全部模块。
- [ ] 360px 手机宽度和桌面宽度没有横向溢出；手机主题抽屉、弹窗、键盘输入可用。
- [ ] Tab 键与屏幕阅读器可以找到主要操作，Esc 能关闭未保存操作的弹窗；表单提交过程中不会重复保存。

## 存储与离线

- [ ] 首次联网打开后，关闭旧页面再打开，离线时仍能载入应用壳、读取和编辑资料。
- [ ] 断网保存后恢复网络，草稿没有消失；应用不会自行上传。
- [ ] 同一个来源打开第二个标签页会提示已有编辑窗口，不会覆盖第一个窗口的数据。
- [ ] 正常关闭第一个窗口后，第二个刷新可继续；PWA 与浏览器窗口同时打开时也检查。
- [ ] 导出备份中没有 GitHub 令牌。
- [ ] 导入前显示主题/模块数量；确认后替换本地资料，导入前恢复副本可下载。
- [ ] 导入非法 JSON、未知版本、无主题的模块、无效状态时拒绝导入，原资料仍存在。

- [ ] 正确配置仓库后拉取能列出已有内容。

- [ ] 上传没有修改时不创建无意义提交。
- [ ] 更新保留仓库中 README 等非资料文件。
- [ ] 保存连接后，刷新、关闭重开、重启普通模式浏览器均恢复登录；不需要重新输入令牌。
- [ ] 从数据库 v1 升级至 v2，主题、草稿、基线不丢失；旧版同一标签页尚存的会话令牌能迁移。
- [ ] 切回本地空间后，再填写相同仓库名能恢复登录；修改仓库名会清空另一仓库的令牌，异步读取不会覆盖手动输入的新令牌。
- [ ] 同一仓库切换分支仍使用该仓库的凭据；不同仓库的凭据互不混入。
- [ ] 点击「清除此设备全部登录」后刷新，所有仓库均需重新填写令牌；仓库设置、主题、编辑草稿保持不变。

- [ ] 令牌过期或撤销后明确报错，原凭据与资料不会被静默删除；保存替代令牌后可继续。
- [ ] 拒绝浏览器持久存储申请不影响正常保存登录；清理站点数据或使用无痕模式时如实反映存储限制。

- [ ] 不同仓库/分支的本地草稿独立，切换后不混入另一份资料。
- [ ] 网络中断时检查是否已经完成 ref 更新；重新拉取能确认真实状态。
- [ ] 仓库分支保护拒绝写入时显示错误，并保留本地资料。

## 两设备 / AI 并发

- [ ] A 删除主题并上传，B 修改其模块后拉取，显示冲突，不静默复活主题。

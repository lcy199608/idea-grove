# 跨设备连接配置 v1

插件不能读取拾念 Web 的 IndexedDB，Web 也不能读取 ChatGPT 的授权。两端用自己的 GitHub 认证，读写同一份无凭据配置。已有 Web 用户点击「同步设置 → 共享 / 更新仓库配置」；没有 Web 设置的用户可以直接在插件配置。共享配置不上传本地游戏资料。

## 配置存在哪里

每个资料仓库的**默认分支**保存 `.shinian/connections/<GitHub 数字用户 ID>.json`，与资料分支可以不同。ID 从已认证的 GitHub profile 获取，不使用仓库所有者代替当前登录用户。示例仅说明格式，不能用作默认值：

```json
{
  "app": "shinian-connection",
  "schemaVersion": 1,
  "githubUserId": "123456",
  "repository": "your-account/your-vault",
  "branch": "main",
  "updatedAt": "2026-09-30T00:00:00.000Z"
}
```

这里只保存仓库定位和更新时间，不保存 token、密码、聊天或主题内容。配置在私有仓库中对其协作者可见。保存默认仓库的行为不构成修改游戏资料的授权。

## 启动与发现

1. 检查 GitHub 工具是否可用，读取当前认证 profile 的数字 ID。没有工具/连接时提示到 ChatGPT「插件/应用 → GitHub」连接；401 提示重新授权。不能假装自动完成登录。工具不可用不代表仓库不存在。
2. 用户本次明确指定了仓库和分支时，先用该目标；只有“配置并记住”“更换默认资料库”等明确意图才持久保存。配置路径由数字 ID 推导，不接受仓库文件传入任意路径。
3. 没有指定时，用 GitHub `list_repositories` 或等价能力分页列出当前连接可访问的仓库（只获取元数据）；按每个仓库真实的 `default_branch` 读取自己的连接文件。优先当前已知目标作为候选，但不能只读旧目标而忽略其他设备新设置。可用代码搜索加速定位候选，但搜索空结果不能证明无配置；完成必要分页/文件探测再下结论。
4. 只接受 app/schemaVersion 匹配、githubUserId 等于当前 ID、repository 等于**承载此文件的仓库全名**（大小写不敏感）、branch 为有效 Git 分支名、updatedAt 为有效 ISO 日期且不显著晚于当前时间的文件。文件上限 16 KB；未知字段保留但不执行。不得顺着远端配置跳到另一个仓库或任意 URL。只读 GitHub API，不读取其他仓库的创意内容。
5. 发现多份有效配置时，以 updatedAt 最新者作为该账号最近选择的默认库；日期相同且目标不同则让用户选择，并询问是否记住新选择。最多扫描 200 个可访问仓库；列表不完整、限流、网络失败或访问不明时如实说发现未完成，不能报告“尚未配置”，不能静默采用可能过期的默认库。大账号可让用户给一个定位提示来缩小范围。
6. 用仓库元数据与目标分支 ref 确认访问。最新目标不可访问时保留设置并提示恢复授权，不自动退回旧库。远端只存在连接配置/README 也不等于已上传主题。
7. 确实未找到时，请用户选仓库（展示少量可访问候选）或输入 `owner/repo` 一次，未给分支使用仓库真实默认分支。说明将记住到该仓库，并让用户明确选择保存；用户已经说“配置并记住”时无需重复业务确认。没有写入工具/权限时可在本次聊天使用，但必须说明未能持久保存。

## 保存或更换默认配置

1. 核对所选仓库和资料分支存在；不替用户创建仓库、分支或修改权限。资料库不得是应用源码仓库。当前账号及连接的权限都需要满足，读成功不能证明可写。
2. 在该仓库默认分支读自己的连接文件。不存在时先确认默认分支可访问，区分 contents 404 与权限失败。已有文件必须通过以上身份、版本和仓库检查，否则停止，不覆盖；保留未知字段。
3. 用当前时间更新 `updatedAt`，写入所选 repository/branch。新文件使用 `create_file`；已有文件使用 `update_file` 并传刚读到的 blob SHA。只改这一个配置文件，单文件原子提交不受多文件主题写入限制。不要改 `idea-vault.json`、README、任何主题或图片。
4. 冲突时先重新读取，若别人已改变目标则让用户决定；不强行覆盖。不以写入“测试文件”检查权限。超时或结果未知时读取配置确认实际结果，不能盲目重试。
5. 只有 GitHub 提交成功才说“已记住，下次可读取”，附真实提交链接。新目标的 updatedAt 使旧目标不再被选中，无需删除其他库的历史配置。电脑和手机必须连接同一 GitHub 账号且能访问配置所在仓库。

Web 的「切回本地空间」「清除此设备全部登录」只影响本机，不删除这份云端连接配置；更换仓库/分支后需再次点共享。配置不会把令牌同步到别的设备。浏览器仍需首次连接自己的 GitHub 令牌，插件走 ChatGPT 的 GitHub 授权。
